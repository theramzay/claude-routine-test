## Microsoft

### Azure
- **Retirement: Pod name dimension in AKS pod platform metrics** (2026-10-06) — From 2027-09-30 the pod name dimension on several Azure Monitor platform metrics (such as `kube_pod_status_phase`) is retired and the metrics become aggregate pod counters. Alerts or dashboards that split by pod name will need to change. [source](https://azure.microsoft.com/updates?id=570232)
- **Retirement: Azure App Service on Azure Stack Hub** (2026-10-06) — Retires 2029-09-30. From 2026-09-30 new installations are unsupported and no new releases or features ship. Existing deployments remain supported until retirement. [source](https://azure.microsoft.com/updates?id=568178)
- **Retirement: Support for Java 8, 11 and 17 on App Service ends 2027-09-01** (2026-10-06) — Apps keep running, but security updates and customer support for these Java versions stop. Plan upgrades to a newer Java version. [source](https://azure.microsoft.com/updates?id=568585)
- **Retirement: Always Encrypted with Intel SGX Enclaves** (2026-10-06) — SGX enclaves in Azure SQL Database retire 2027-10-31 as SGX-enabled DC-series hardware is phased out. Microsoft recommends moving to VBS enclaves, which don't depend on specific hardware. [source](https://azure.microsoft.com/updates?id=569236)
- **Public Preview: AKS on bare metal now on Ubuntu** (2026-10-06) — AKS can now run Kubernetes directly on bare metal using Ubuntu, with no virtualization layer, which gives workloads such as AI direct access to local hardware. [source](https://azure.microsoft.com/updates?id=573782)
